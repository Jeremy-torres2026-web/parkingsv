# Parking SV

Parking SV🚕 es un sitio web desarrollado para facilitar la búsqueda de parqueos en El Salvador. La plataforma permite que los usuarios publiquen información sobre parqueos disponibles y que los clientes registrados puedan consultar estas publicaciones para encontrar opciones de estacionamiento que se ajusten a sus necesidades.

El proyecto busca centralizar información sobre parqueos en un solo lugar, permitiendo visualizar datos relevantes de cada publicación y facilitando la conexión entre personas que ofrecen espacios de estacionamiento y personas que necesitan encontrar uno📌.
